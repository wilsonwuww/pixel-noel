# Pixel Noël v0.1.0 — 功能、视觉与性能验收

记录日期：2026-11-24。构建和浏览器检查均真实执行；下列结果不代表所有设备或浏览器的性能承诺。

## 实际结果

- `npm run build`：TypeScript 检查与 Vite 生产构建成功。
- `npm test`：31 项通过，1 项按设计跳过（桌面项目不执行手机专用触摸用例），0 失败。
- 实际使用 Chrome，桌面 1512×1000，移动视口 390px，额外通过 Chrome 调试协议触发真实触摸事件流。
- 默认场景：43 件独立对象；12 类挂饰、24 件家具与装饰、两棵独立树体母版、两种四姿态宠物。
- 运行时 npm 生产依赖：0。
- 生产构建全部文件合计：10,517,579 bytes（10.52 MB，含按需素材与授权文本）。
- JavaScript：50,276 bytes；CSS：13,318 bytes；构建终端 gzip JS 约 20.6 KB、CSS 约 3.8 KB。
- 默认首屏同源网络传输：7,166,238 bytes（7.17 MB，包含 HTTP 计量开销）。额外家具与云杉按需加载。
- 本地默认素材解码和存档读取完成：桌面 112 ms、移动视口 107 ms。来自本地预览，不代表公网加载时间。
- 179 个有效帧间隔采样：桌面平均 60 FPS、P95 帧间隔 16.7 ms；移动视口平均 60 FPS、P95 16.7 ms。
- 测量期间页面异常：0。原始数据与逐文件体积见 [performance.json](performance.json)。

## 真实视觉审查与修正

逐次查看了建筑、裸树、家具、挂饰、宠物以及真实页面截图。用户的室内与雪村参考在开发中补齐，并用于光色、构图与材质方向；没有将参考图作为运行时背景，也没有随项目发布。

发现并修正：地毯比例导致覆盖墙面；火焰层次覆盖前景椅子；地毯选择区域抢选前景家具；同层重叠对象的选择顺序与绘制顺序不一致；手机缩放浮层遮挡前景；树型切换不必要地重新约束已有挂饰位置。修复后通过对应浏览器用例。

## 取舍、后置与未覆盖范围

- 首屏 7.17 MB 超过 3 MB 建议目标。为保留木纹、松针、织物细节，采用无损资源和按需扩展包，不通过强制降低关键素材分辨率满足预算。
- 手机结果是同一台开发电脑的移动视口、像素密度和触控模拟，不是真实手机硬件。Safari、Firefox、低端 Android 和真实 iPhone 尚未验证。当前不承诺普通手机 30 FPS 已验收。
- 树冠路径遮罩为近似轮廓，尚无逐针叶遮挡；树枝浓郁度调整色彩而非真实枝叶数量；精细分区换色蒙版、更多树种与冰晶素材后置。
- 家具表面范围是约束而非自动吸附；桌上物件不会随桌子一起移动。无镜像素材不提供任意转向。GIF/精灵视频导入未做。
- 原创像素工坊提供网格拟合和手动配色，未提供自动颜色协调。整体场景与画板是两套有界历史，不混合撤销。
- 个人角色目前仅发色、衣色可调；发型、服装、配饰完整模块与照片映射后置，避免引入模型资源和不可靠外观识别。
- 音乐与壁炉环境声为原创 Web Audio 合成，须主动点击才播放。音频感受尚无真人听感评测；不能把视觉用例计为听感验收。
- 当前资源为高密度 AI 辅助像素风美术；没有声称所有母版已经通过严格统一网格/限定色板的数学审查。默认场景不等同参考图逐像素复刻。
