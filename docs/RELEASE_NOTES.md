# Pixel Noël v0.1.0

Craft your own little Christmas.

**[Enter the cabin](https://wilsonwuww.github.io/pixel-noel/)** · [中文说明](https://github.com/wilsonwuww/pixel-noel/blob/main/README.zh-CN.md)

An independent, browser-only Christmas creative studio: a warm Nordic pixel cabin, two separate tree masters, 12 editable ornament types, 24 furniture/decor assets, hand-drawn light strands and ribbons, four palettes, a transparent pixel workshop, reusable original designs, pets, snow, fireworks and a pixel fireplace. Room, Tree and Cozy modes share one scene. IndexedDB auto-save, bounded undo/redo, JSON backup and PNG capture work locally without an account or runtime API key.

Validation: 31 browser checks passed plus one intentionally skipped desktop touch-only duplicate, on both the built preview and the actual public Pages site. Actions build, deploy and public smoke verification all succeeded. Independent local frame sampling averaged 60 FPS; the mobile profile is desktop-hosted viewport/touch emulation, not a physical handset benchmark.

Known limits: default first-load transfer is about 7.17 MB, exceeding the 3 MB aspiration to preserve lossless material detail. Canopy masking is approximate; color tinting is not a segmented material mask. The optional personal character has only hair/clothing colors; full wardrobe, hair/accessory modules and local photo mapping are deferred. Physical mobile and cross-browser validation are still needed. See the full [QA report](https://github.com/wilsonwuww/pixel-noel/blob/main/docs/QA.md).
