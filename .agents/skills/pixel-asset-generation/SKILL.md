# pixel-asset-generation

Read ASSET_SPEC.md. Generate original isolated sprites with true alpha; common perspective, pixel density, scale and upper-right warm light. Keep each sprite fully within its cell with margin. Include author, provenance, native bounds, anchor, surface and license in the manifest. Confirm observed source rectangles, not assumed equal grid geometry. Inspect alpha over light and dark backgrounds. Preserve detail with lossless delivery. Do not run unreviewed external scripts.
