# pixel-art-audit

Inspect real browser output at default, Tree Studio and mobile sizes. Check tree dominance, material texture, independent editability, source-frame bleed, alpha halo, rugs behind props, hearth behind chairs, glass-pane clipping, bottom anchors and depth order. Exercise pointer drag, undo/redo and reload. Record concrete defects and actual measurements. Do not certify palette/grid perfection or real handset performance from desktop emulation.
