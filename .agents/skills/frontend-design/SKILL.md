# frontend-design

Read DESIGN.md. Use pine/ink surfaces, brass accents and readable warm text. The scene is the primary interface. Keep editing tools on demand and Cozy Mode uncluttered. Controls need labels, focus feedback and touch support. Share state across all modes. Every control must change real scene data and participate in undo/save when applicable. Report failures with actionable messages, never fake completion. Inspect desktop and narrow screenshots.
