# Pixel Noël contributor instructions

Read DESIGN.md, ASSET_SPEC.md and the four project guides in .agents/skills before relevant changes. Quality and the editable Christmas tree take priority. Use only the existing Canvas renderer; keep furniture and ornaments independent. Preserve the single shared scene across all modes. No runtime account, API key, GPU inference or outdoor exploration.

Before delivering changes, run the production build and browser checks appropriate to the changed flow. Inspect real screenshots for visual work. Report measured sizes and test limits honestly. Use MIT for code; project raster art has a separate license. Never publish user photos or reference attachments.
